Vercel AI SDK를 써봤다. `create-next-app`으로 프로젝트를 만들고 해봄

라이브러리 설치

```bash
npm install ai @ai-sdk/react zod
```

`.env.local` 에 AI_GATEWAY_API_KEY 설정한다. vercel dashboard에서 발급받을 수 있다.
