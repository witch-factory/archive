주변 사람들과 이야기하며 얻은 AI와 함께 쓰면 좋은 것들

일하는 방식도 추상화할 수 있다면 좋음. 가령 내가 좋아하지 않는 코드를 쳐내는 거라든지

## 에이전트 관련 도구

oh my pi: pi 기반의 확장된 에이전트 개발환경. 내가 쓰는 중
기억도 mnemopi라고 해서 기본적으로 제공한다

https://github.com/can1357/oh-my-pi

openspec: spec driven development 도와주는 도구. 구현 전에 명세 만드는 걸 해줌. omp랑 연동 가능

https://github.com/Fission-AI/openspec

vercel eve: 에이전트 만드는 프레임워크. 에이전트의 next.js를 목표로 한대

https://eve.dev/

이외에도 vercel oss(https://vercel.com/oss) 보면 신기한 게 많다.

## 스킬

ponytail: 과도한 추상화나 새로운 구현, 불필요한 코드 작성 방지

https://github.com/DietrichGebert/ponytail

emil skill: UI 디자인, 애니메이션 개선

https://github.com/emilkowalski/skills

vercel agent skills: react 성능, vercel 최적화, 웹 디자인 가이드라인 등 전반적인 웹 지식

https://github.com/vercel-labs/agent-skills

seo skill for claude code

https://github.com/zubair-trabzada/geo-seo-claude

## UI 라이브러리

shadcn ui(base ui가 현재 가장 많이 쓰이긴 하는데 react aria도 고려해볼만)

https://ui.shadcn.com/

shaders: WebGPU 셰이더, 굴절, 유체 효과, 그라디언트

https://shaders.com/

motion: 이전의 framer motion. 애니메이션 황제

https://motion.dev/

magic ui: 다양한 애니메이션 컴포넌트, 효과

https://magicui.design/

lucide-react: heroicon과 아이콘계 양대산맥

https://lucide.dev/guide/react/

assistant ui: ai 에이전트 만들 때 쓸만한 UI 라이브러리

https://www.assistant-ui.com/
